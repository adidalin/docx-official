# 公文格式转换工具 (docx-official)

基于GB/T 9704标准的公文格式转换工具，支持AI智能分析和文本纠错。

## 功能特点

| 功能 | 说明 |
|------|------|
| 智能结构识别 | 自动识别标题、一级/二级/三级/四级标题、正文、落款 |
| AI文本纠错 | 检测错别字、漏字、日期格式错误 |
| 落款自动处理 | 拆分发文机关署名和成文日期，右空四字排版 |
| 日期格式化 | 中文日期自动转为阿拉伯数字（如"二〇二五年"→"2025年"） |
| 页码自动添加 | -X-格式，宋体小四号，居中 |
| 表格格式化 | 表头加粗、居中，统一行间距 |
| 文本清洗 | 去除多余空格、处理非自然回车、合并错误段落 |

## 格式标准

依据GB/T 9704《党政机关公文格式》标准：

| 元素 | 字体 | 字号 | 行距 |
|------|------|------|------|
| 标题 | 方正小标宋简体 | 二号 (22pt) | 30磅 |
| 一级标题 | 黑体 | 三号 (16pt) | 28磅 |
| 二级标题 | 楷体 | 三号 (16pt) | 28磅 |
| 三级标题 | 仿宋 (加粗) | 三号 (16pt) | 28磅 |
| 四级标题 | 仿宋 | 三号 (16pt) | 28磅 |
| 正文 | 仿宋 | 三号 (16pt) | 28磅 |
| 页码 | 宋体 | 小四号 (12pt) | - |

**页面设置：**
- 纸张：A4 (210×297mm)
- 页边距：上3.7cm、下3.5cm、左2.8cm、右2.6cm
- 首行缩进：2字符
- 落款：右空四字

## 快速开始

### 安装依赖

```bash
pip install python-docx requests
```

### 设置API密钥（可选）

```bash
# Windows
set DEEPSEEK_API_KEY=your-api-key

# Linux/Mac
export DEEPSEEK_API_KEY=your-api-key
```

### 使用方法

```bash
# 基本用法
python convert_official.py input.docx

# 指定输出文件
python convert_official.py input.docx output.docx

# 不使用AI（纯规则判断）
python convert_official.py input.docx --no-api
```

## 字体要求

| 字体 | 文件名 | 用途 |
|------|--------|------|
| 方正小标宋简体 | FZSTK.TTF | 标题 |
| 黑体 | simhei.ttf | 一级标题 |
| 楷体 | simkai.ttf | 二级标题 |
| 仿宋 | simfang.ttf | 正文/三级/四级标题 |

缺少字体时自动使用系统替代字体。

## AI功能说明

设置`DEEPSEEK_API_KEY`环境变量后，可启用以下AI功能：

1. **智能结构分析**：准确识别文档标题级别，处理复杂排版
2. **文本纠错**：检测错别字、漏字、事实错误，自动修正

不设置API密钥时，使用规则判断，仍可正常工作。
