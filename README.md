# 公文格式转换工具 (docx-official) 🤖

**AI智能公文排版工具 — 自动识别、智能纠错、一键转换**

基于GB/T 9704标准的公文格式转换工具，深度融合**AI大模型能力**，实现从"粘贴复制"到"智能识别"的跨越。调用DeepSeek API完成文档结构分析、文本纠错、过长标题智能拆分，API调用从3次优化为最多2次。

> **AI工具接入 | AI智能识别 | 智慧办公**

## 功能特点

| 功能 | 说明 | AI加持 |
|------|------|--------|
| ⚡ 智能结构识别 | 自动识别标题、一级/二级/三级/四级标题、正文、落款 | ✅ AI分析段落层级 |
| 🔍 AI文本纠错 | 检测错别字、漏字、日期格式错误、标点符号错误 | ✅ AI语义理解 |
| ✂️ 过长标题智能拆分 | 检测超过40字的一级/二级标题，API自动截断为简洁标题+正文 | ✅ AI确定最佳断点 |
| 📄 落款自动处理 | 拆分发文机关署名和成文日期，右空四字排版 | ✅ AI从文末提取 |
| 📅 日期格式化 | 中文日期自动转为阿拉伯数字（如"二〇二五年"→"2025年"） | ✅ AI识别日期 |
| 🔢 页码自动添加 | -X-格式，宋体小四号，居中 | 规则处理 |
| 📊 表格格式化 | 表头加粗、居中，统一行间距 | 规则处理 |
| 🧹 文本清洗 | 去除多余空格、处理非自然回车、合并错误段落、删除Markdown符号 | ✅ AI判断段落归属 |
| 🛡️ JSON容错 | 自动修复API返回的未转义换行符等JSON格式问题 | 保障AI输出稳定 |
| ⚡ API优化 | 综合分析一次调用完成纠错+结构，最多2次API调用完成全部处理 | 智能调度 |

## 格式标准

依据GB/T 9704《党政机关公文格式》标准：

| 元素 | 字体 | 字号 | 行距 |
|------|------|------|------|
| 标题 | 方正小标宋简体 | 二号 (22pt) | 30磅 |
| 一级标题 | 黑体 | 三号 (16pt) | 28磅 |
| 二级标题 | 楷体 | 三号 (16pt) | 28磅 |
| 三级标题 | 仿宋 (加粗) | 三号 (16pt) | 28磅 |
| 四级标题 | 仿宋 | 三号 (16pt) | 28磅 |
| 正文 | 仿宋 | 三号 (16pt) | 28磅 |
| 页码 | 宋体 | 小四号 (12pt) | - |

**页面设置：**
- 纸张：A4 (210×297mm)
- 页边距：上3.7cm、下3.5cm、左2.8cm、右2.6cm
- 首行缩进：2字符
- 落款：右空四字

## 快速开始

### 安装依赖

```bash
pip install python-docx requests
```

### 设置API密钥（强烈推荐）

```bash
# Windows
set DEEPSEEK_API_KEY=your-api-key

# Linux/Mac
export DEEPSEEK_API_KEY=your-api-key
```

### 使用方法

```bash
# 基本用法
python convert_official.py input.docx

# 指定输出文件
python convert_official.py input.docx output.docx

# 不使用AI（纯规则判断）
python convert_official.py input.docx --no-api
```

## AI智能引擎（核心亮点 🤖）

本工具最大的特色是**深度接入AI大模型**，让公文排版从"机械套模板"升级为"智能理解文档"。

### 一句话概括

> **AI自动识别文档结构 + 智能纠错 + 自动拆分过长标题 = 你只需要粘贴，剩下的交给AI**

### 设置AI（强烈推荐）

```bash
set DEEPSEEK_API_KEY=your-api-key
```

### AI做了什么？

| AI能力 | 传统工具 | 本工具（AI接入） |
|--------|----------|-----------------|
| 标题识别 | 靠手动设置样式 | AI自动判断段落层级 |
| 错别字纠正 | 无法处理 | AI语义理解，自动修正 |
| 过长标题 | 手动拆分 | AI确定最佳截断位置 |
| 落款提取 | 手动复制粘贴 | AI从文末自动识别 |
| 网络文档清洗 | 需要手动整理 | AI判断段落归属 |

### 处理流程（最多2次API调用）

```
第1次: 综合分析 ── 文本纠错 + 结构分析（合并为1次调用）
第2次: 标题拆分 ── 过长标题智能截断（仅当存在长标题时调用）
```

### AI功能详解

1. **综合分析**（纠错+结构）
   - 检测错别字、漏字、日期格式、标点符号错误
   - 识别文档标题层级（标题→一级→二级→三级→四级→正文→落款）
   - 自动从文末识别发文机关和成文日期

2. **过长标题智能拆分**
   - 检测超过40字的一级标题（"一、"）和二级标题（"（一）"）
   - API自动确定最佳截断位置，保持语义完整
   - 截断后：标题保留序号+核心概念，剩余内容自动转为首行缩进正文
   - 示例：`一、防汛物资储备标准调整（1）各车间...` → 标题`一、防汛物资储备标准调整` + 正文`（1）各车间...`

3. **JSON容错机制**
   - 自动修复API返回的未转义换行符
   - 多重JSON解析兜底（提取、清理、重试）
   - 任何一步失败自动降级为规则判断
